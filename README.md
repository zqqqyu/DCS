# Capturing Stable HDR Videos Using a Dual-Camera System

This repository contains the dataset for the paper **"Capturing Stable HDR Videos Using a Dual-Camera System"**. The dataset was captured using two MV-CS032-10GC industrial cameras, designed to provide high-quality, HDR video sequences for video reconstruction and other HDR-related research.
